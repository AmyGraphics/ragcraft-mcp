# RAGCraft MCP Server 🧠🔍⚡

Universal Autonomous RAG (Retrieval-Augmented Generation) Knowledge Architecture, Semantic Chunking, Vector Embeddings & Hybrid Search MCP Server for **Cursor, Claude Code, and Windsurf**.

## 🌟 Core Capabilities:
- 🧩 **Semantic Chunking Engine:** Splits unstructured text, markdown, or code into context-preserving chunks with sliding window token overlap and heading hierarchy.
- 💰 **Embedding & Vector DB Cost Calculator:** Computes one-time indexing and recurring query costs across OpenAI, Voyage, Cohere, and Pinecone/Qdrant/Vectorize.
- ⚡ **Hybrid Search Query Synthesizer:** Generates SQL/SDK queries combining sparse BM25 full-text search with dense vector cosine similarity via Reciprocal Rank Fusion (RRF).
- 📊 **RAG Precision Benchmark & Eval:** Measures Context Relevance, Answer Faithfulness, and Mean Reciprocal Rank (MRR) with automated LLM judges.
